# Educational Content Expander

A command-line interface (CLI) tool designed for educators to expand concise lesson plan bullet points and short phrases into complete, grammatically coherent sentences using an $N$-gram statistical language model with add-$k$ smoothing.

---

## What It Does

Educators often draft lesson plans using condensed notes, syllabus outlines, or bullet points (e.g., `- Cellular respiration`, `• Active learning strategies`). This tool:
1. Strips bullet indicators and normalizes user input.
2. Ingests domain-specific educational corpora across key curriculum subjects.
3. Builds an $N$-gram transition frequency matrix smoothed with add-$k$ Laplace estimation.
4. Predicts subsequent words using either deterministic greedy search or temperature-controlled weighted sampling.
5. Produces complete, punctuated, and contextually grounded sentences ready for lesson plans and curriculum drafts.

---

## Data Source & Corpus Details

The model is trained on a curated educational text corpus spanning cross-disciplinary foundational domains:
- **Biology & Life Sciences**: Cellular respiration, photosynthesis, DNA genetics, mitosis/meiosis, ecosystems, and evolutionary natural selection.
- **Physical Sciences & Physics**: Thermodynamics, conservation of energy, Newton's laws of motion, Einstein's theory of relativity, electricity and charge flow.
- **Earth & Environmental Sciences**: Plate tectonics, volcanic/seismic boundaries, hydrological cycle, evaporation/precipitation biomes.
- **Mathematics**: Linear equations, Cartesian coordinates, quadratic formulas, probability scales.
- **History & Social Studies**: River valley civilizations, Industrial Revolution urbanization, American Revolution constitutional principles, Renaissance, World War II.
- **Pedagogy & Classroom Instruction**: Active learning strategies, formative assessments, empirical laboratory inquiry, critical analysis and evidence evaluation.

Users can also provide their own specialized textbooks, syllabus outlines, or lesson archives via the `--corpus <path>` flag.

## Performance Evaluation, Baseline & Limitations

### Baseline
- **Method**: Trigram language model ($n=3$) with add-$k$ Laplace smoothing ($k=0.1$) and lower-order backoff ($n-1 \dots 1$).
- **Vocabulary Size**: 195+ unique domain-specific tokens across 29 curriculum sentences in the default corpus.
- **Smoothing Guarantee**: Non-zero probability floor $P(w \mid context) > 0$ for all vocabulary tokens, preventing out-of-vocabulary crashes on novel educator prompts.

### Strengths
- **Fast and Self-Contained**: Runs in milliseconds entirely on CPU with zero external API dependencies or GPU requirements.
- **Deterministic & Reproducible**: Fully reproducible runs when specifying `--seed <int>`.
- **Subject-Specific Guidance**: Maintains educational terminology (e.g., matching *photosynthesis* with *light energy*, *cells* with *glucose*).

### Limitations & Where It Falls Short
- **Limited Horizon Context**: As a Markovian $N$-gram model with $n \le 3$, it only considers the preceding 1–2 words for transitions. It lacks long-range semantic memory compared to transformer models.
- **Corpus Sensitivity**: If a subject is not represented in the training text, generation relies on lower-order backoff and smoothing, which can transition into words from adjacent educational subjects (e.g. transitioning from *natural selection* to *electric charge* if a bigram is shared).
- **Sentence Boundary Truncation**: When reaching the user's `--max-words` threshold, sentences may cut off near prepositional phrases if an explicit end-of-sentence token (`</s>`) was not sampled beforehand. Supplying a custom in-depth domain corpus with `--corpus` significantly alleviates topic-drifting.

## Installation & Reproducibility

Dependencies are pinned in `requirements.txt`:
```
pytest==8.3.3
```

```bash
# Clone the repository
git clone https://github.com/aryan-0018/educational-content-expander.git
```

## CLI Reference

```
python -m app.cli [command] [options]
```

### Commands:
- `expand`: Expands a bullet point or phrase into a full sentence.
- `suggest`: Displays top next-word probability distributions.
- `hello`: Sanity check to confirm CLI wiring.

### Options for `expand`:
| Flag | Type | Default | Description |
|---|---|---|---|
| `text` | `str` | *(required)* | Bullet point or input phrase |
| `--n` | `int` | `3` | $N$-gram order (e.g. 2 for bigram, 3 for trigram) |
| `--k` | `float` | `0.1` | Add-$k$ smoothing hyperparameter |
| `--max-words` | `int` | `12` | Word budget for expansion |
| `--strategy` | `greedy` \| `sampling` | `greedy` | Decoding strategy |
| `--temperature` | `float` | `0.7` | Temperature for sampling stochasticity |
| `--seed` | `int` | `None` | Random seed for exact reproducible sampling |
| `--corpus` | `path` | `None` | Path to custom `.txt` corpus |
| `--output` | `path` | `None` | Save output directly to file |
